# online-library
 Онлайн кітапхана жүйесі (Online Library System)
Жобаның мақсаты мен мүмкіндіктері
**Мақсаты:** Пайдаланушыларға кітаптар каталогын қарауға, қажетті кітапты іздеуге, брондауға және кітапхана қорын басқаруға мүмкіндік беретін ыңғайлы веб-платформа құру.

### Негізгі мүмкіндіктер:
* **Пайдаланушылар үшін:**
  * Жүйеге тіркелу және кіру (аутентификация).
  * Кітаптар каталогын қарау, іздеу, жанр және автор бойынша сүзу, сұрыптау.
  * Кітапты брондау/қарызға алу.
  * Жеке кабинет арқылы алынған кітаптар тарихын қарау.
* **Әкімші (Admin) үшін:**
  * Кітаптарды қосу, өңдеу және өшіру (CRUD операциялары).
  * Пайдаланушылардың брондау өтінімдерін бақылау.
## Беттер тізімі (Интерфейс)
1. `index.php` — Басты бет (Кітаптар каталогы, іздеу және сүзу панелі).
2. `book.php` — Кітаптың толық сипаттамасы мен брондау беті.
3. `login.php` / `register.php` — Жүйеге кіру және тіркелу формалары.
4. `profile.php` — Жеке кабинет (Алынған кітаптар тізімі).
5. `admin/` — Әкімші панелі (Кітаптарды басқару - CRUD).
## Дерекқор құрылымы (MySQL - ER Structure)

Жобада **3 негізгі кесте** қолданылады:

### 1. `users` (Пайдаланушылар кестесі)
| Баған (Column) | Түрі (Type) | Сипаттамасы |
| `id` | INT (PK, AI) | Пайдаланушы ID-і |
| `username` | VARCHAR(50) | Пайдаланушы аты |
| `email` | VARCHAR(100) | Электронды пошта |
| `password` | VARCHAR(255) | Хэштелген құпиясөз (`password_hash`) |
| `role` | ENUM('user','admin') | Пайдаланушы рөлі |
| `created_at` | TIMESTAMP | Тіркелген уақыты |

### 2. `books` (Кітаптар кестесі)
| Баған (Column) | Түрі (Type) | Сипаттамасы |
| `id` | INT (PK, AI) | Кітап ID-і |
| `title` | VARCHAR(255) | Кітап атауы |
| `author` | VARCHAR(150) | Авторы |
| `genre` | VARCHAR(100) | Жанры |
| `year` | INT | Шыққан жылы |
| `cover_image` | VARCHAR(255) | Мұқаба суретінің жолы |
| `description` | TEXT | Қысқаша сипаттамасы |

### 3. `borrowed_books` (Брондау кестесі)
| Баған (Column) | Түрі (Type) | Сипаттамасы |
| `id` | INT (PK, AI) | Брондау ID-і |
| `user_id` | INT (FK -> users.id) | Алған пайдаланушы ID-і |
| `book_id` | INT (FK -> books.id) | Алынған кітап ID-і |
| `borrow_date` | DATE | Алынған күні |
| `return_date` | DATE | Қайтару күні |
| `status` | ENUM('active','returned') | Брондау статусы |
## Қолданылатын технологиялар
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (PDO)
* **Database:** MySQL
* **Version Control:** Git & GitHub
